伪装参数✳

只填写要替换的字段；留空则保持原值。例如 Linux localhost 6.1.174-g638ecc425319 #1 SMP PREEMPT Wed Sep 16 23:10:11 CEST 2026 aarch64 Android 中，只修改从 6.1.174-g638ecc425319 到 2026 的两段。

UTS 字段留空 = 原始值

每项最多 64 个 ASCII 字符；不支持引号、反斜杠。修改 release 后必须重启设备，才能让 Zygote 的缓存值同步。

ABOUT / 03

生效范围

此模块只调整 UTS 的 release 和 version，让 uname、/proc/version 与 /proc/sys/kernel/* 中相应字段一致。

release 变更会延迟到下次重启；其他配置保存时模块会短暂卸载并重新加载。失败时请查看服务日志。
